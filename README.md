# Nombre del proyecto
SISES
## Integrantes
- Cristhian Cepeda
## Descripción
Proyecto universitario desarrollado con **HTML, CSS y JavaScript** que permite consultar una lista de estudiantes, buscarlos y registrar nuevos mediante un formulario validado
## Tecnologías
- HTML
- CSS
- JavaScript
## Funcionalidades
- Página principal con menú de navegación y tarjetas de resumen.
- Lista de estudiantes con búsqueda en tiempo real.
- Formulario de registro con validación (campos obligatorios, correo y teléfono).
- Mensaje de confirmación al registrar.
- Diseño responsive con menú desplegable en móviles.
