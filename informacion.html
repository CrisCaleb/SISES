Información del sistema

¿Qué es?

El Sistema de Estudiantes es una aplicación web académica que permite visualizar y registrar estudiantes de una institución. Fue desarrollado como proyecto universitario usando únicamente HTML, CSS y JavaScript.

Funcionalidades

  • Lista de estudiantes: tabla con ID, nombre, apellido, carrera y acciones.
  • Búsqueda en vivo: filtra la tabla mientras escribes.
  • Registro: formulario con campos nombre, apellido, carrera, correo y teléfono.
  • Validación: campos obligatorios, formato de correo y teléfono.
  • Diseño responsive: se adapta a computadoras, tablets y celulares.

Tecnologías utilizadas

  • HTML5 para la estructura.
  • CSS3 (variables, flexbox, grid, media queries) para el diseño.
  • JavaScript para la validación y la búsqueda.
  • Git y GitHub para el control de versiones (ramas y Pull Requests).
